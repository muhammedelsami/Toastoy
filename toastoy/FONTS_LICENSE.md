# Bundled fonts

The fonts in `src/main/res/font/` are redistributed from [Google Fonts](https://fonts.google.com)
under the [SIL Open Font License, Version 1.1](https://openfontlicense.org).
Each family is bundled as a single variable font (`wght` axis). Where the upstream font has extra axes
(Cairo `slnt`, Readex Pro `HEXP`) they were pinned to their default values with fontTools to reduce size.
